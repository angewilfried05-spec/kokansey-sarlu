## Introduction

L'application KOKANSEY SARLU est un système de gestion complet pour votre entreprise agricole. Elle permet de gérer :

- **Spéculations** : Types de cultures (maïs, riz, etc.)
- **Clients** : Gestion de votre clientèle
- **Employés** : Gestion du personnel
- **Camions** : Gestion du parc automobile
- **Ventes** : Suivi des ventes de produits
- **Factures** : Émission et gestion des factures
- **Dépenses** : Suivi des dépenses opérationnelles
- **Stocks** : Gestion des inventaires
- **Récoltes** : Suivi des récoltes par campagne
- **Campagnes** : Gestion des campagnes agricoles
- **Rapports** : Statistiques et analyses

## Première connexion

### Accès à l'application

**Version Web :**
- URL : http://65.109.236.120
- Navigateur recommandé : Chrome, Firefox, Edge

**Version Desktop :**
- Lancez l'application installée sur votre ordinateur
- L'application se connecte automatiquement au serveur

### Connexion

1. Sur la page de connexion, entrez vos identifiants :
   - **Nom d'utilisateur** : `KOKANSEY GROUP`
   - **Mot de passe** : `admin123`

2. Cliquez sur le bouton **"Se connecter"**

3. ⚠️ **Important** : Changez votre mot de passe après la première connexion pour des raisons de sécurité.

### Changement de mot de passe

1. Connectez-vous à l'application
2. Allez dans le menu **Utilisateurs**
3. Sélectionnez votre compte
4. Cliquez sur **Modifier**
5. Entrez votre nouveau mot de passe
6. Sauvegardez les modifications

## Gestion des spéculations

Les spéculations représentent les types de cultures ou produits que vous gérez (ex: maïs, riz, manioc, etc.).

### Créer une spéculation

1. Allez dans le menu **Spéculations**
2. Cliquez sur le bouton **"Nouvelle spéculation"**
3. Remplissez les informations :
   - **Nom** : Nom de la spéculation (ex: Maïs)
   - **Description** : Description détaillée (optionnel)
   - **Prix unitaire** : Prix de vente par unité
   - **Unité de mesure** : kg, tonne, sac, etc.
4. Cliquez sur **"Enregistrer"**

### Modifier une spéculation

1. Allez dans le menu **Spéculations**
2. Cliquez sur la spéculation à modifier
3. Modifiez les informations nécessaires
4. Cliquez sur **"Mettre à jour"**

### Supprimer une spéculation

1. Allez dans le menu **Spéculations**
2. Cliquez sur la spéculation à supprimer
3. Cliquez sur **"Supprimer"**
4. Confirmez la suppression

⚠️ **Attention** : La suppression d'une spéculation affectera les données liées (ventes, stocks, etc.).

## Gestion des clients

### Créer un client

1. Allez dans le menu **Clients**
2. Cliquez sur **"Nouveau client"**
3. Remplissez les informations :
   - **Nom** : Nom du client ou de l'entreprise
   - **Téléphone** : Numéro de contact
   - **Email** : Adresse email (optionnel)
   - **Adresse** : Adresse physique
   - **Notes** : Informations supplémentaires
4. Cliquez sur **"Enregistrer"**

### Gérer les opérations client

1. Sélectionnez un client
2. Cliquez sur **"Opérations"**
3. Vous pouvez voir :
   - Historique des achats
   - Factures émises
   - Paiements reçus
   - Solde actuel

---

## Gestion des employés

### Créer un employé

1. Allez dans le menu **Employés**
2. Cliquez sur **"Nouvel employé"**
3. Remplissez les informations :
   - **Nom complet** : Nom de l'employé
   - **Poste** : Fonction (ex: Chauffeur, Ouvrier, Comptable)
   - **Téléphone** : Numéro de contact
   - **Salaire** : Salaire mensuel
   - **Date d'embauche** : Date de début
4. Cliquez sur **"Enregistrer"**

### Gérer les affectations

Les employés peuvent être affectés à :
- Camions (chauffeurs)
- Tâches spécifiques
- Campagnes agricoles

## Gestion des camions

### Créer un camion

1. Allez dans le menu **Camions**
2. Cliquez sur **"Nouveau camion"**
3. Remplissez les informations :
   - **Immatriculation** : Numéro de plaque
   - **Marque/Modèle** : Type de véhicule
   - **Capacité** : Capacité de chargement (en tonnes)
   - **Chauffeur assigné** : Sélectionnez parmi les employés
   - **Statut** : En service / En maintenance / Hors service
4. Cliquez sur **"Enregistrer"**

### Suivi des camions

- **Historique des trajets** : Voir les livraisons effectuées
- **Maintenance** : Enregistrer les opérations d'entretien
- **Consommation carburant** : Suivre la consommation

## Gestion des ventes

### Enregistrer une vente

1. Allez dans le menu **Ventes**
2. Cliquez sur **"Nouvelle vente"**
3. Remplissez les informations :
   - **Client** : Sélectionnez le client
   - **Spéculation** : Type de produit vendu
   - **Quantité** : Montant vendu
   - **Prix unitaire** : Prix par unité
   - **Date** : Date de la vente
   - **Facture** : Associer à une facture existante ou créer une nouvelle
4. Cliquez sur **"Enregistrer"**

### Modifier une vente

1. Sélectionnez la vente à modifier
2. Modifiez les informations nécessaires
3. Cliquez sur **"Mettre à jour"**

### Annuler une vente

1. Sélectionnez la vente
2. Cliquez sur **"Annuler"**
3. Confirmez l'annulation

---

## Gestion des factures

### Créer une facture

1. Allez dans le menu **Factures**
2. Cliquez sur **"Nouvelle facture"**
3. Remplissez les informations :
   - **Client** : Sélectionnez le client
   - **Date d'émission** : Date de la facture
   - **Date d'échéance** : Date de paiement
   - **Ventes à inclure** : Cochez les ventes à facturer
4. Le montant total est calculé automatiquement
5. Cliquez sur **"Générer facture"**

### Envoyer une facture par WhatsApp

1. Sélectionnez la facture
2. Cliquez sur **"Envoyer par WhatsApp"**
3. Le PDF de la facture sera généré et envoyé au client

⚠️ **Note** : Cette fonctionnalité nécessite que WhatsApp soit configuré et activé.

### Marquer comme payée

1. Sélectionnez la facture
2. Cliquez sur **"Marquer comme payée"**
3. Entrez le montant et la date de paiement
4. Sauvegardez

### Imprimer une facture

1. Sélectionnez la facture
2. Cliquez sur **"Imprimer"**
3. Le PDF sera généré pour impression

---

## Gestion des dépenses

### Enregistrer une dépense

1. Allez dans le menu **Dépenses**
2. Cliquez sur **"Nouvelle dépense"**
3. Remplissez les informations :
   - **Type** : Carburant, Salaires, Maintenance, Fournitures, etc.
   - **Montant** : Montant de la dépense
   - **Date** : Date de la dépense
   - **Description** : Détails de la dépense
   - **Camion associé** : Si lié à un véhicule (optionnel)
   - **Campagne** : Si lié à une campagne (optionnel)
4. Cliquez sur **"Enregistrer"**

### Catégories de dépenses

- **Carburant** : Essence, diesel pour véhicules
- **Salaires** : Paiements des employés
- **Maintenance** : Réparations et entretien
- **Fournitures** : Matériel et équipements
- **Transport** : Frais de transport
- **Divers** : Autres dépenses

---

## Gestion des stocks

### Enregistrer un mouvement de stock

1. Allez dans le menu **Stocks**
2. Cliquez sur **"Nouveau mouvement"**
3. Sélectionnez le type :
   - **Entrée** : Réception de stock
   - **Sortie** : Utilisation de stock
4. Remplissez les informations :
   - **Spéculation** : Type de produit
   - **Quantité** : Montant du mouvement
   - **Date** : Date du mouvement
   - **Motif** : Raison du mouvement
5. Cliquez sur **"Enregistrer"**

### Consultation des stocks

- **Stock actuel** : Quantité disponible par produit
- **Historique** : Tous les mouvements de stock
- **Alertes** : Stocks bas (si configuré)

---

## Gestion des récoltes

### Enregistrer une récolte

1. Allez dans le menu **Récoltes**
2. Cliquez sur **"Nouvelle récolte"**
3. Remplissez les informations :
   - **Campagne** : Sélectionnez la campagne agricole
   - **Spéculation** : Type de culture
   - **Quantité récoltée** : Montant de la récolte
   - **Date de récolte** : Date de la récolte
   - **Zone/Champ** : Localisation
   - **Qualité** : Évaluation de la qualité
4. Cliquez sur **"Enregistrer"**

### Suivi des récoltes

- **Par campagne** : Voir les récoltes par campagne
- **Par spéculation** : Voir les récoltes par type de culture
- **Rendement** : Calculer le rendement par hectare

## Gestion des campagnes

### Créer une campagne

1. Allez dans le menu **Campagnes**
2. Cliquez sur **"Nouvelle campagne"**
3. Remplissez les informations :
   - **Nom** : Nom de la campagne (ex: Campagne Hivernale 2026)
   - **Date de début** : Date de début de la campagne
   - **Date de fin** : Date de fin prévue
   - **Superficie** : Surface cultivée (en hectares)
   - **Objectifs** : Objectifs de production
4. Cliquez sur **"Enregistrer"**

### Suivi d'une campagne

- **Récoltes** : Voir toutes les récoltes de la campagne
- **Dépenses** : Dépenses liées à la campagne
- **Ventes** : Ventes des produits de la campagne
- **Rentabilité** : Analyse de la rentabilité

## Rapports et statistiques

### Rapports disponibles

1. **Rapport des ventes**
   - Période personnalisable
   - Par client
   - Par spéculation
   - Export en Excel/PDF

2. **Rapport des dépenses**
   - Par catégorie
   - Par période
   - Par campagne

3. **Rapport des stocks**
   - État actuel
   - Mouvements
   - Valorisation

4. **Rapport de rentabilité**
   - Par campagne
   - Par spéculation
   - Analyse coût/bénéfice

### Générer un rapport

1. Allez dans le menu **Rapports**
2. Sélectionnez le type de rapport
3. Définissez les filtres (date, catégorie, etc.)
4. Cliquez sur **"Générer"**
5. Exportez en Excel ou PDF si nécessaire

## Gestion des utilisateurs

### Rôles disponibles

- **ADMIN** : Accès complet à toutes les fonctionnalités
- **GERANT** : Gestion quotidienne, pas d'accès aux utilisateurs
- **COMPTABLE** : Accès aux finances et factures
- **MAGASINIER** : Gestion des stocks uniquement

### Créer un utilisateur

1. Allez dans le menu **Utilisateurs** (réservé aux admins)
2. Cliquez sur **"Nouvel utilisateur"**
3. Remplissez les informations :
   - **Nom d'utilisateur** : Identifiant de connexion
   - **Mot de passe** : Mot de passe (minimum 6 caractères)
   - **Nom complet** : Nom de la personne
   - **Email** : Adresse email (optionnel)
   - **Téléphone** : Numéro de contact (optionnel)
   - **Rôle** : Sélectionnez le rôle approprié
4. Cliquez sur **"Enregistrer"**

### Modifier un utilisateur

1. Sélectionnez l'utilisateur
2. Modifiez les informations nécessaires
3. Changez le rôle si besoin
4. Cliquez sur **"Mettre à jour"**

### Supprimer un utilisateur

1. Sélectionnez l'utilisateur
2. Cliquez sur **"Supprimer"**
3. Confirmez la suppression

⚠️ **Note** : Vous ne pouvez pas supprimer votre propre compte.

### Journal d'audit

Le système enregistre toutes les actions importantes :
- Création/modification/suppression de données
- Connexions des utilisateurs
- Actions sensibles

Pour consulter le journal :
1. Allez dans le menu **Utilisateurs**
2. Cliquez sur **"Journal d'audit"**

Les notifications WhatsApp permettent d'envoyer :

## Conseils et bonnes pratiques

### Sécurité

- **Changez régulièrement votre mot de passe**
- **Ne partagez pas vos identifiants**
- **Déconnectez-vous après utilisation**
- **Utilisez des mots de passe forts** (lettres, chiffres, caractères spéciaux)

### Gestion des données

- **Sauvegardez régulièrement** (le serveur effectue des sauvegardes automatiques)
- **Vérifiez vos données** avant de supprimer
- **Utilisez les rapports** pour analyser votre activité
- **Gardez un historique** des transactions importantes

### Performance

- **Utilisez les filtres** pour réduire les temps de chargement
- **Exportez les rapports** pour analyse hors ligne
- **Fermez les onglets inutilisés**

## Support et aide

### Problèmes fréquents

**Je ne peux pas me connecter**
- Vérifiez vos identifiants
- Vérifiez votre connexion internet
- Contactez l'administrateur

**Les données ne s'affichent pas**
- Vérifiez les filtres
- Actualisez la page (F5)
- Vérifiez votre connexion

**L'application est lente**
- Vérifiez votre connexion internet
- Réduisez la quantité de données affichées avec les filtres

### Contact

En cas de problème persistant :
- Contactez l'administrateur système
- Consultez le journal d'audit pour identifier les erreurs
- Vérifiez les logs de l'application

## Glossaire

- **Spéculation** : Type de culture ou produit agricole
- **Campagne** : Période de production agricole
- **Facture** : Document de paiement émis aux clients
- **Stock** : Inventaire des produits disponibles
- **Récolte** : Quantité récoltée lors d'une campagne
- **Audit** : Journal des actions effectuées dans le système
